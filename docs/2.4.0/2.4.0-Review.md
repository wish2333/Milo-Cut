## 2. 架构决策

### 2.1 保留现有组件边界

本版只调整 CSS token、模板 class、状态表现和键盘入口，不改变 Vue 页面边界、bridge API、Project/ProjectPatch、TaskManager 或导出业务逻辑。这样可以将 UI 风险限制在视觉层和局部 DOM 交互层。

### 2.2 单一主操作色

Action Blue 作为主操作、当前项、链接和 focus 色；绿色、黄色和红色只表达“保留、待确认、删除”等业务状态。Export 页将视频导出设置为 primary，其余输出格式降为 secondary，避免多个高饱和按钮竞争视觉焦点。

### 2.3 语义 token 优先于原始 Tailwind 色

新增 `mc-button-*` 语义按钮类和 `bg-status-*` 状态类。保留少量绿色文本用于“已确认/已保留/差异插入”等状态信息；这些颜色不再承担普通主按钮层级。

### 2.4 保留 v-memo 性能优化

Timeline 中的 `v-memo` 虽被 lint 规则标记为不适用于当前模板结构，但它是长字幕列表的既有性能策略。本版保留该优化，并仅对该局部规则做 ESLint 注释豁免，没有删除它换取形式上的 lint 清洁。

## 4. 已知限制

1. 尚未在真实 PyWebView 窗口中做 macOS/Windows 截图回归。
2. 设置弹层、字幕修正全屏页和少量右键菜单仍有历史 Tailwind 原始类。
3. Export 的 OTIO、Crossfade、Clean Export 等技术选项保留英文，后续可统一产品文案。
4. 本版没有重构建议面板为抽屉，也没有调整 Workspace 的可拖拽布局比例。
5. `docs/demo/plan.md` 是本次发布前已经存在的未跟踪文档，按用户要求的 release-workflow 全量暂存规则一并纳入；没有对应 Demo 代码变更。
