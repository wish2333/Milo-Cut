# v2.0.0 → v2.1.0 手动检查清单 (GUI 端到端)

> **用途**: 在真实 Windows 桌面环境中，打开 Milo-Cut PyWebView 窗口逐项手工验证。
> **检查日期**: ________     **检查人**: ________     **浏览器/窗口**: PyWebView
> **分支**: dev-2.1.0     **测试项目**: 任一口语视频 + SRT 字幕

---

## 使用方法

1. 启动: `uv run dev.py`
2. 依次执行以下检查项，每项完成后在 `[ ]` 中标记 `x`
3. 发现 bug 时在「备注」栏记录复现步骤和错误信息
4. 如某项不适用 (如无 LLM Key)，标记 `N/A` 并说明
