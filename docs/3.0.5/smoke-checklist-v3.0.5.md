## 2. beta.1 轮（R5.0 / R5.1 / R5.2 / R5.3 / R5.13）

| # | 项 | 操作 | 观测重点 |
|---|---|---|---|
| B1-1 | duplicate 幂等防呆（R5.0，数据安全级） | 同一区间**重复框选**提交两次；再对同区间**双击**；再用**时间码**重复提交同一起止 | 第二次起只出**轻提示（info，约 2.5s 自消）**，不新增覆层/条目；**undo 栈不涨**——按一次 Ctrl+Z 应回退到「第一次提交之前」的状态，而不是吃掉一次重复提交（R5.0 的核心手感：重复提交不污染撤销历史） |
| B1-2 | 翻译失败 → 补译全链（R5.1+R5.2+R5.3，**本版最高风险面**） | 用非 json_mode 提供商跑翻译；构造部分批失败（断网/换错 key/超长文本触发限流皆可） | ① **完成的批次落盘生效**（不再整任务零写入），toast「**翻译完成：N 段未覆盖，可一键补译（见 AI 助手面板）**」（error/5s）；② 面板 uncovered 区**可读可定位**：`mm:ss` 时间 + **20 字**文本预览；③ 全批失败文案中文化且含出路：「**翻译失败：{failed}/{total} 批处理失败（批 {ids}），本次未写入任何译文；可直接重试补译；反复失败建议更换模型或检查网络**」；④ **一键补译只重跑缺口**（观察批数明显少于全量、日志无重复段），成功 toast「**本次补译 N 段**」，若仍有缺口「**仍有 N 段未覆盖，可一键补译（见 AI 助手面板）**」；⑤ 补译合并为**单 patch、revision 只 +1**（不出现整工程闪刷）；⑥ **undo 一次回退整个补译结果**；⑦ 全程无缺口时 toast「**翻译完成，已切换到译文轨「X」**」且列表自动切轨 |
| B1-3 | 重译同语言自动路由（R5.3 边界） | 对已存在同语言翻译轨的工程再次点翻译 | 不再硬拒；**自动路由为补译**，toast 明示「**本次补译 N 段**」（N = 缺口段数，非全量段数）；若走拒绝路径，AI 面板错误区应附指引「**（波形区右键该轨 → 清空轨道/删除轨道）**」（R5.14），且该出路在当前视图**真的可达**（右键菜单里有这两项） |
| B1-4 | 取消中性提示 + 成本可见（R5.1） | 翻译跑到中途点取消 | toast = 「**翻译已取消，已消耗约 X tokens**」（info/约 3s），**中性措辞**（无「失败/错误」字样）、X 为真实消耗量级（非 0、非 NaN）；取消后已落盘批次保持 |
| B1-5 | 连续 429 串行降级可见（R5.1） | 用易限流模型连发（或人为压小并发）触发连续 429 | 面板/Timeline 出现**串行降级提示（含 "(serial)" 字样）**；降级后任务仍推进不静默卡死 |
| B1-6 | token 量级预估显示（R5.13） | 打开 AI 面板翻译卡（未跑之前） | 预估串形如「**约 N 批 · 约 X 万 token**」；**N 与真实派发批数一致或极接近**（前端复刻后端切批算法：批窗 30 + 字符预算 4000，非朴素 ceil(段数/30)——短段多时二者差异明显，可用 60 段短文工程对照） |

## 3. beta.2 轮（R5.4 批量审阅收口）

| # | 项 | 操作 | 观测重点 |
|---|---|---|---|
| B2-1 | 批量按钮作用域（轨隔离） | 主轨视图与副轨视图各跑一次纠错，产生两轨待审集；在**主轨视图**点「接受高置信度」 | **副轨待审集不被吞掉**（切到副轨仍在）；确认框文案含**轨名 + 条数**；「全部」态明示**〈全部轨道〉** |
| B2-2 | 清除作用域 | 在某一轨点「清除」 | 只清当前轨，**他轨待审保留**；清除后列表刷新不整页闪 |
| B2-3 | 批量 undo 一次回退 | 批量接受后按一次 Ctrl+Z | **一次回退到位**（文本 + 审阅条目 + 轨道/分析层同时复原——快照三层并集 segments/tracks/analysis）；不出现「回退一半」（如文本回退但徽标计数没回） |

## 4. beta.3 轮（R5.5 / R5.6 / R5.7 / R5.9 / R5.10 / R5.11 / R5.15）

| # | 项 | 操作 | 观测重点 |
|---|---|---|---|
| B3-1 | 纠错取消即时性（R5.5，**A Top2 用户痛点**） | 大工程（≥300 段）纠错跑到中途点取消 | **约 1s 内返回**（对照翻译侧同款手感，不应出现数秒卡顿）；串行降级路径下取消同样即时；取消后已产出的待审集不被误清 |
| B3-2 | keep 重跑可感知（R5.6） | 建若干 keep 区间 → 跑自动裁剪 → 再改 keep → **重跑** | 重跑 toast = 「**新增 {N} 条、按保留区间清除 {M} 条旧区间**」（M=0 时只报新增）；确认单条 keep/删除时 toast **按动作差异化**（keep 与删除文案不同，不再是通用「已确认」） |
| B3-3 | 导出页 keep×删除说明（R5.6③） | 存在 confirmed 删除时进导出页 | 计数行下方出现静态说明句「**保留区间与删除区间重叠时，导出按删除处理**」；无 confirmed 删除时该句不渲染 |
| B3-4 | trim 冻结矩阵（R5.7，**主/副轨不对称是刻意结果**） | 进「编辑模式」后：拖副轨块边缘 trim；打开副轨 lane 菜单（建段/清空轨/删除轨）；同样操作主轨 | 副轨：trim 拖不动 + 结构操作被拦截并 toast「**请退出编辑模式后重试**」；**主轨：trim/菜单/手势全部照常可用（2.x 基线，零变化）**——主轨被误拦即为异常；退出编辑模式后副轨能力**完全恢复** |
| B3-5 | 时间码输入族（R5.11） | 建议面板「+ 时间码」：分别输入 `1:12.5`、`72.5`、超范围值（如 10 / 9999）、非法值（`abc`、`1:2:3`） | `1:12.5` 与 `72.5` **等价解析为 72.5s**；超范围**clamp 回显**（夹到时间轴实际范围并把输入框数值改写为夹后值）；非法值报错文案「**请输入有效的起止时间（秒 12.5 或 分:秒 1:12.5）**」；成功 toast「**已添加保留范围 Xs - Ys**」（删除同理） |
| B3-6 | 取播放头 | 播放到某处暂停 → 点「取播放头」 | 起止输入框**预填当前播放头**（0.1s 取整），可继续微调后提交 |
| B3-7 | 审阅 modal 按轨过滤 + 「全部」切换（R5.11） | 双轨各有待审 → 打开审阅弹窗 → 切「按当前轨 / 全部」 | 默认**只显示当前列表轨**的条目（切换轨道后集合跟着变）；切「全部」显示两轨全集；**批量操作在「全部」态才作用于全轨**（与 B2-1 呼应） |
| B3-8 | 纠错结果不「假空」（R5.11 reset 延后） | 已有审阅列表时再启动一次新纠错 | **跑的过程中旧列表仍可见**（不瞬间变「暂无」）；新结果返回后才整体替换；零结果的一次运行也会正确清空 |
| B3-9 | 覆层三态语义 + 中文 title（R5.9/R5.10） | 建 pending/confirmed/rejected 三态范围；hover 各覆层；建一个与删除区间相交的 keep | 颜色 = 动作（红删除/蓝保留）、透明度 = 状态（pending 半透明）；hover 提示中文语义化，形如「**保留范围 12.0s - 15.0s（待确认）**」（状态词 = 待确认/已确认/已拒绝，秒数一位小数）；相交时分号附注「**；与重叠区间导出按删除处理**」；**rejected 范围不再渲染**（拒绝后覆层立刻消失，无残留） |
| B3-10 | 建段 toggle 半亮 + 气泡消泡（R5.10） | 建段 toggle 在不同模式下的显示；打开确认气泡后按 Esc / 点气泡外 | toggle 在不可用时呈**半亮（降档）而非完全隐藏**（可感知存在）；气泡 **Esc 与点外都能关闭**，且点外关闭**不触发底层建段/选区**（消泡正确） |
| B3-11 | 删除/级联删除 toast（R5.15） | 删一个单段；再删一整条轨（级联） | 单段：「**已删除 1 段，可 Ctrl+Z 撤销**」；整轨：「**已删除 N 段及其关联数据，可 Ctrl+Z 撤销**」且 **N = 该轨真实段数**（数一下核对）；**仍无确认框**（裁决维持，undo 兜底）；Ctrl+Z 能完整恢复（含关联数据） |
| B3-12 | 副轨纠错不照抄主轨（R5.12，弱观察项） | 对翻译副轨跑纠错，主轨存在明显不同措辞 | 结果应只修 ASR 错字，**不把主轨文本抄进副轨**（prompt 已加语义说明；此项为主观质量观察，异常记录样本即可） |

## 5. RC 轮（全量回归 + 观测债 + 签字）

| # | 项 | 操作 | 观测重点 |
|---|---|---|---|
| RC-1 | **千段观测值回填（本版必填债，record-3.0.4 §6 ③ 顺延）** | 千段级工程跑一次完整翻译（默认并发）与一次质量模式（串行），分别计时 | 回填三组数：**总耗时 / 消耗 token / 实际批数**（并发 vs 串行各一组）；串行组**时延约为并发 5 倍**是否符合预期（偏差过大需登记，影响 README 标注可信度） |
| RC-2 | 质量模式开关（R5.8，config 默认关） | 关：跑一次翻译；开：`llm_translation_quality_mode` 置真后重跑 | **默认关时行为与 3.0.4 完全一致**（无串行、无上下文注入，逐字节等价面）；开启后**串行派发**且批 N 携批 N-1 定稿译文（跨批术语/人称一致性主观变好）；补译同受开关约束 |
| RC-3 | 3.0.4 沿承①：翻译全链 + undo 三层一致 | 翻译 → 接受/拒绝若干 → undo 多次 | 每步 undo 都**三层一致**（文本/审阅条目/轨道状态同步回退），无「半回退」 |
| RC-4 | 3.0.4 沿承②：纠错双轨 + 轨徽门控 | 主/副轨各跑纠错 | 副轨视图纠错卡可用且**锁定当前轨（显式轨徽）**；主轨已删段的绑定译文自动跳过 |
| RC-5 | 3.0.4 沿承③：编辑扫掠副轨 | 列表「编辑」进入整列文本编辑，切轨前有未决编辑 | 扫掠覆盖副轨行；**切轨前未决编辑先落盘**（不丢字） |
| RC-6 | 3.0.4 沿承④：lane 建段 | 建段模式下点副轨 lane 空白 | 能建段（multi 与 **basic** 两路径都要试——basic 路径为 3.0.5 D4 补测面：与相邻段重叠时**不崩、时间轴排序正确、重载后完整**） |
| RC-7 | 3.0.4 沿承⑤：语义搜索 | 副轨视图下搜索 | 结果**文本与时间戳正确**，点击定位到主轨命中段 |
| RC-8 | 3.0.4 沿承⑥：手动范围全链 | 范围标记 toggle → 框选 → 气泡二选一 → 建议面板分组 → 确认 → 导出 | 全链贯通；pending 范围**不影响**跳播/进度条红罩/导出预览；confirmed keep **不被自动裁剪吃掉** |
| RC-9 | 3.0.4 沿承⑦：keep 重跑场景 | 见 B3-2 | 与 B3-2 合并执行，重点验**重跑不产生重复覆层** |
| RC-10 | 双平台差异面 | Win/mac 各复跑 B1-1、B3-1、B3-4、B3-10 | 快捷键（Ctrl/Cmd+Z）、Esc 消泡、拖拽 trim 手感、toast 层级在两平台一致 |
