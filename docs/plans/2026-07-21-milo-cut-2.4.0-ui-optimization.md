# Milo-Cut v2.4.0 UI Optimization Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 Milo-Cut 前端收敛为以视频和字幕为核心的专业编辑工作台，并完成 v2.4.0 P0 UI 优化。

**Architecture:** 保留现有 Vue 组件边界、bridge API 和数据模型；先在共享 CSS token 层统一颜色、字体、间距、圆角与焦点状态，再逐页替换业务组件中的原始颜色和容器样式。Workspace 只做视觉层级与状态表现优化，不改变时间线数据流。

**Tech Stack:** Vue 3, TypeScript, Tailwind CSS 4, DaisyUI 5, Vitest, Bun.
