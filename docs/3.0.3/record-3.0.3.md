## 5. 遗留清单（下版候选 / 待办）

1. **smooth 默认值 A/B 裁决**：beta.2 ★ 真机混合操作样本（瞬时 vs 平滑）→ 裁决默认值并回写 SPEC M2-1；若真机掉帧/空白复现，优先复查 `SCROLL_ECHO_WINDOW_MS=100` 宽限参数与 140ms 时长。
2. **副轨删除确认策略再评估**：现「无确认框 + undo 兜底」，若真机误删反馈集中，考虑轻量二次确认（与波形块菜单对齐）。
3. **谓词表第 4 行测试深化**：删除捕获断言现依赖 3.0.2 既有 handler（本版仅接线覆盖）；`createWorkspaceActions` 若获得轻量实例化通路，补真实链路用例。
4. **README_zh 功能段滞后**：3.0.x 特性仅补列表副轨一条，多行时间线/堆叠时间线等段落待集中回填。
5. **挂载墙钟 perf gate 环境差**：本机 happy-dom 挂载约 18–35ms（阈值 8ms），开发机差异明确后考虑给该 gate 加环境标注或独立阈值（需用户裁决，涉及断言修改红线）。
