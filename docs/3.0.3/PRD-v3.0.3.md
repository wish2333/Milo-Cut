## 0. 版本定位

v3.0.3 的主题只有一个：**副轨管理闭环**。v3.0.0 引入副轨、v3.0.1 补齐波形侧增删改、v3.0.2 补齐多行显示与行内生命周期——但**字幕列表（右列）始终只显示主轨**：副轨文本无法在列表中查看与编辑，双语工作流必须来回切换波形区才能改一个字。本版把列表升级为「轨感知」：track 选择器切换显示源，副轨段在列表中获得与主轨同级的查看/编辑/定位/删除能力。

打磨批（顺带）来自 3.0.2 的两条遗留登记：跟随平滑动画调度器（瞬时写入手感待真机验证后的正式实现）与列表行右键菜单 kbd 角标（v3.0.1 面未动项）。

## 1. S1：字幕列表副轨切换与编辑（主项）

### R1.1 列表 track 选择器

**需求**：字幕列表头部新增轨切换控件（主轨 / 各副轨，副轨项显示名称与段数徽章）。选中副轨时列表数据源切换为该轨 `track.segments`，行渲染复用现有列表行组件；选中主轨时与 v3.0.2 完全一致。

**边界**：选择器是纯视图态（reactive ref），不触碰 `active_timeline_id` 语义、不新建 timelines fork、不产生任何 patch；副轨被删除（`delete_track`）时选择器自动回退主轨。

**验收**：主轨/副轨切换往返无状态残留；删除当前查看中的副轨后列表无悬空引用。

### R1.2 副轨段列表渲染

**需求**：副轨列表行显示 text / start / end（时长换算与格式化沿主轨行既有工具）；显示绑定标记（该段存在 binding 时标注联动，数据来自既有 bindings 层）；空轨显示空态 + 「新建字幕」入口（走 `add_track_segment`）。

**验收**：双语工程副轨段全量可见；绑定标记与波形区一致；空轨可从列表直接建段。

### R1.3 副轨文本编辑（列表内）

**需求**：双击副轨行进入文本编辑 → 提交走 `update_track_segment({ text })`；乐观更新 + 300ms 防抖合并（同段同字段）+ 失败回滚，沿 useTrackEdit 既有链路扩展 text 字段（后端 text 路径已就绪，project_service.py:1382 `allowed_fields = {"start","end","text"}`）。

**验收**：编辑提交无回跳；非法输入（后端拒绝）回滚并 toast；防抖合并不产生中间 patch 抖动。

### R1.4 副轨时间数值编辑与定位

**需求**：列表行 start/end 可数值编辑（走同一 `update_track_segment`，后端 clamp/重叠拒绝语义，拒绝即回滚）；单击行 = seek 定位（沿 `handleListSeek` 既有通路）；播放跟随高亮当前副轨段（沿主轨列表跟随语义）。

**验收**：越界/重叠输入被拒绝且回滚；seek 双向（列表→波形、播放→列表高亮）正确。

### R1.5 副轨行操作与撤销谓词

**需求**：副轨行右键菜单：定位 / 编辑 / 删除此条字幕（走 `delete_track_segment`，无确认框——撤销已覆盖，沿 3.0.2 裁决）。**撤销捕获层谓词表**（与波形侧对齐，本表为裁决）：

| 操作 | 谓词 | 捕获层 |
|---|---|---|
| 列表文本编辑（text） | 恒真 | `["tracks"]`（text 不触发 binding 重建） |
| 列表时间编辑（start/end） | 该段存在绑定 | `["tracks","bindings"]` |
| 同上 | 无绑定 | `["tracks"]` |
| 删除此条字幕 | 恒真 | `["tracks","bindings"]`（删除可能移除绑定） |

**验收**：undo/redo 对称原子——时间编辑（有绑定段）回退后列表、波形 lane、绑定偏移三层一致。

## 2. S2：跟随平滑动画调度器

**需求**：

- R2.1 编排层单例动画调度器（rAF）：跟随/跳转的 scrollTop 写入由瞬时赋值改为 ease-out 动画（目标 ~140ms）；**每帧单写**、动画期间新目标平滑重定向（不叠加双动画）
- R2.2 **时间窗回环抑制**：沿 `markManualScroll` / `noteAutoScroll` / `consumeAutoScroll` 既有回环分类扩展——手动滚动打断动画；播放时钟回调期间不启动新动画（3.0.2 空白嫌疑的直接防御）
- R2.3 瞬时路径保留为回退：设置开关 localStorage `milocut:timeline-follow-smooth:v1`；**默认值在 beta.1 真机 A/B 后裁决**（3.0.2 smooth 实验曾因连续回放空白嫌疑回退，本版要求真机证据再定默认）
- R2.4 vitest：手动滚动打断、组件卸载清理、回环抑制三路径、重定向不叠加

**验收**：多行滚动/播放跟随手感提升目视可辨；回放期间无空白/跳变复现；开关往返即时生效。
