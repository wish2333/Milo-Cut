## 2.2.0功能展望

- 补充优化一个功能：字幕纠错
  如果当前已经有快速清理的“部分删除”意见，也将这些意见跟随segment（不再某一批次中的意见不跟随）发送给字幕纠错LLM输入以辅助其进行修改
  可能需要修改后端数据解析、整合、传递逻辑以及LLM功能提示词
- 修复一个功能缺陷：精华提取
  当前导出界面并没有一个功能按钮支持到精华提取内容的导出，也不知道后端实现了导出精华内容的方式了吗，并且这一方式不能漏掉用户手动添加、删除等操作
  此外，还需验证精华提取功能是否能在LLM设置未配置的情况下由用户手动添加管理，而非冻结住功能不给用
  因此，2.1.1版本中的精华提取功能在实际上并不可用，需要重点标记，并在2.2.0版本中进行修复更新
- 目前2.1.1版本开发至今仍未对工作流模式进行验证，请也先标记为不可用功能提醒用户（在文档和release note中而非修改代码），并在2.2.0版本中进行修复更新
